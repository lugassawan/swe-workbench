# Language catalog

All `swe-workbench` language rules. These are plain `.md` files under `rules/`, not skills — load one on demand with `cat "$CLAUDE_PLUGIN_ROOT/rules/<name>.md"` when it applies.

- `language-bash` — Bash idioms: strict mode, quoting, parameter expansion, arrays, pipefail, trap cleanup, idempotency, heredocs, and POSIX portability. → `rules/language-bash.md`
- `language-csharp` — C#/.NET idioms: .NET 8 LTS, nullable reference types, records, pattern matching, async/await, dependency injection, options, LINQ, and performance. → `rules/language-csharp.md`
- `language-dart` — Dart idioms: null safety, async, Futures/Streams, widget composition, Riverpod/Bloc app architecture. → `rules/language-dart.md`
- `language-go` — Go idioms: error handling, concurrency, and standard library usage. → `rules/language-go.md`
- `language-java` — Java idioms: records, sealed types, virtual threads, streams, JDK 21+ patterns. → `rules/language-java.md`
- `language-kotlin` — Kotlin idioms: null safety, coroutines, sealed interfaces, scope functions, Flow. → `rules/language-kotlin.md`
- `language-python` — Python idioms: PEP 8, type hints, dataclasses, asyncio, generators, pytest. → `rules/language-python.md`
- `language-ruby` — Ruby idioms: Ruby 3.x pattern matching, blocks, procs, lambdas, Enumerable, Comparable, frozen string literals, error handling, and testing. → `rules/language-ruby.md`
- `language-rust` — Rust idioms: ownership, borrowing, lifetimes, traits, iterators, error handling. → `rules/language-rust.md`
- `language-sql` — SQL idioms: query optimization, EXPLAIN plans, schema design, transactions, deadlock avoidance, window functions, CTEs, and pagination. → `rules/language-sql.md`
- `language-swift` — Swift idioms: optionals, value types, actors, async/await, protocols, Result builders. → `rules/language-swift.md`
- `language-typescript` — TypeScript/JavaScript idioms: strict mode, discriminated unions, async patterns, Node. → `rules/language-typescript.md`
